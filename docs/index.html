Price first, then time

Part 2 · The two-thread pipeline

A ring buffer with no locks

The ingestion thread pushes requests into SpscQueue; the matching thread pops them and owns the book alone, so the book needs no mutex. The real queue holds 65,536 slots. This one holds 16 so you can watch it fill. Slow the consumer down to see tryPush start returning false.

Each counter has one writer. head_ and tail_ sit on separate 64-byte cache lines (alignas(64)), so a write by one thread never invalidates the line the other thread is writing. A release store of tail_ paired with an acquire load publishes each slot.

Fix 1 · pre-size the order-id hash map
8.5 → 14.0 M/s

Reserving orderIndex_ up front removed multi-millisecond rehash stalls and roughly doubled single-thread throughput.

Fix 2 · busy-poll before yield()
420 → 250 ns

Spinning briefly on an empty queue before yielding the CPU cut median latency by about 40%.
